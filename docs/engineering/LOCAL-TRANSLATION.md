# English to Simplified Chinese

Download and verify OPUS-MT in **Models**. To translate during a recording, enable **Live transcription** and **Translate English to Simplified Chinese** before Start. Translation is off by default. The worker queues each selected English final in the same transaction as its ASR revision and starts inference after that transaction commits. The governor gives committed audio and ASR work priority. With insufficient headroom or an unavailable model, the queued finals remain available for **Translate English transcript** in Sessions. [Issue #12](https://github.com/sagehou/VoiceLedger/issues/12)

The shared SQLite migration adds an append-only translation history. Each revision records its exact source revision, parent, target language, author, creation time, and model provenance for machine output. Edits create a separate manual revision. A machine rerun leaves the latest manual revision selected even when the source has changed. The clients label that revision as outdated until a user saves a new correction. Retrying a completed machine job for the same source and model does not insert a duplicate. The client keeps the current edit visible if saving fails.

The installation pins the public INT8 conversion of Helsinki-NLP OPUS-MT at `d45e5f86313be8e29629dda5f01ec98eba26e947`. The hosted comparison below used a different conversion of the original OPUS-MT archive. The 384 MiB preflight memory allowance is a conservative engineering estimate derived from that hosted baseline. The runtime checks current memory headroom again before loading, and the speech resource governor can defer optional work. Target device peak RAM, latency and battery measurements remain **BLOCKED** pending #18. ## Hosted candidate comparison

The Actions workflow evaluates 12 synthetic final utterances with the same corpus on isolated Linux x64 runners. Each model and its runtime dependencies are SHA-256 pinned. The inference processes see only the loopback interface. The reports record the source commit, corpus and model hashes, CPU, timings, process peak RSS and all synthetic outputs. The reported model size counts the files used for inference. [Workflow](../../.github/workflows/translation-evaluation.yml) · [Corpus](../../contracts/fixtures/translation-en-zh-v1.json) · [Actions evidence](https://github.com/sagehou/VoiceLedger/actions/runs/45363849951)

The Bergamot jobs used one worker and beam size 1 on EPYC 7763 runners. OPUS-MT used one thread, the source archive's beam size 6, and the Simplified Chinese target token on a Xeon 6975P-C runner.

The original OPUS-MT archive used here carries CC BY 4.0, as stated in its included license. The Hugging Face conversion has its own Apache-2.0 label. The hosted CTranslate2 run converts the original weights to int8. Any redistribution of those converted weights needs the original attribution, license and conversion disclosure.
